# AI Study: AI 기초부터 AI Agent까지

백엔드 개발자를 준비하며 AI를 공부하고 정리하는 저장소입니다.
개념은 벨로그에 정리하고, 직접 돌려본 실습 코드는 이 저장소에 기록합니다.

## 학습 방향

- AI 전문가가 아니라, 웹·백엔드 개발자가 AI를 이해하고 필요할 때 활용할 수 있는 수준을 목표로 합니다.
- 이론을 먼저 정리한 뒤, 작은 샘플로 직접 실습합니다.
- 각 개념마다 아래 네 가지를 정리합니다.
  1. 한 줄로 설명하면 무엇인가
  2. 어디에 쓰이는가
  3. 직접 해본 것
  4. 필요할 때 어떻게 활용하는가
